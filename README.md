# 802 BOT — نسخه فقط با توکن روبیکا

این نسخه از `rubpy.BotClient` و Bot API استفاده می‌کند. ورود با شماره تلفن، اکانت شخصی، فایل سشن، ویس‌چت و پخش آهنگ در این نسخه وجود ندارد.

## تنظیم اولیه و امنیت

توکن را در کد یا GitHub قرار ندهید. در Railway از بخش **Variables** متغیر زیر را بسازید:

- `RUBIKA_BOT_TOKEN` = توکن تازه‌ای که از BotFather گرفته‌اید

شناسه مالک در مقدار `OWNER_ID` ابتدای `main.py` قرار دارد. اگر مالک تغییر کرده، همان مقدار را با شناسه صحیح جایگزین کنید.

**اگر توکن قبلی در مخزن عمومی منتشر شده، آن را باطل کنید و فقط توکن تازه را در Railway Variables بگذارید.**

## نصب و اجرا

```bash
python -m pip install -r requirements.txt
python main.py
```

## Railway

1. مخزن را به Railway وصل کنید.
2. در صورت نیاز به ماندگاری دیتابیس، Volume با مسیر `/app/data` بسازید.
3. در بخش Variables متغیر `RUBIKA_BOT_TOKEN` را با توکن تازه تنظیم کنید؛ توکن را در فایل یا GitHub نگذارید.
4. Deploy با Dockerfile انجام می‌شود.

## دستورات

### PV
- `/start` — منوی خصوصی و نمایش شناسه
- `/owner` — بررسی مالک ثبت‌شده
- `جزوه علوم`
- `جزوه ریاضی`
- `خروج`

فایل‌های جزوه را در `resources/science.pdf` و `resources/math.pdf` بگذارید.

### گروه (فقط مالک)
- `فعال` — فعال‌سازی پایش گروه
- `راهنما`
- ریپلای به پیام و `اخطار`
- ریپلای به پیام و `حذف سکوت`

## قابلیت‌ها

- فیلتر واژه‌های نمونه فارسی، انگلیسی و ترکی و قابل توسعه بودن فهرست در `main.py`
- فیلتر چند ایموجی تنظیم‌شده
- تشخیص استیکر و GIF در صورت دریافت فیلد رسانه توسط Bot API
- تشخیص اسپم ساده (۵ پیام در ۳۰ ثانیه)
- حذف پیام تخلف و پیام‌های بعدی فرد محدودشده با `Update.delete()`
- سکوت داخلی دائمی برای توهین و ۱۰ دقیقه‌ای برای استیکر/GIF/اسپم
- گزارش تخلف و اخطارها به PV مالک
- پاسخ هوشمند اختیاری؛ برای فعال‌سازی مقدار `OPENAI_API_KEY` را در ابتدای `main.py` وارد کنید

## مجوزهای لازم

ربات باید در گروه دسترسی حذف پیام داشته باشد؛ در غیر این صورت حذف پیام شکست می‌خورد و در گزارش مالک مشخص می‌شود. Bot API مستندشده متد حذف پیام از طریق `Update.delete()` دارد، اما محدودیت این پروژه برای یک کاربر با حذف پیام‌های بعدی او پیاده‌سازی شده، نه با مجوز سکوت اختصاصی در سطح سرور.

## تست

این سورس با ساختار مستندشده RubPy BotClient نوشته شده است. قبل از استفاده واقعی، آن را با یک گروه آزمایشی و دسترسی‌های لازم تست کنید؛ رفتار زندهٔ API و مجوزهای گروه از اینجا قابل تأیید نیست.
