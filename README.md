# 802 بات — روبیکا

ربات مدیریت گروه روبیکا با قابلیت‌های کامل:

- آنتی‌فحش (فارسی + انگلیسی + ترکی + ایموجی)
- جلوگیری از استیکر، گیف و اسپم
- سکوت دائمی برای فحش + سکوت ۱۰ دقیقه‌ای برای استیکر/گیف/اسپم
- در زمان سکوت، تمام پیام‌های کاربر پاک می‌شود
- کال + قطع کال + پخش آهنگ در ویس‌کال
- فقط فرمان از اونر (`/owner`)
- کارها از اکانت عادی | پاسخ‌ها از بات
- نوتیف کامل به پیوی اونر

## نصب

```bash
pip install -r requirements.txt
```

## تنظیمات

فایل `.env` بسازید:

```
BOT_TOKEN=توکن_بات
ACCOUNT_SESSION=account802
```

## اجرا

```bash
python main.py
```

برای Railway از Dockerfile استفاده کنید (ffmpeg خودکار نصب می‌شود).

## دستورات

**پیوی:**
- `/owner` → ثبت به عنوان اونر
- `/start` → منوی جزوه

**گروه (فقط اونر):**
- `فعال` → فعال‌سازی بات در گروه
- `کال` → شروع ویس‌کال
- `قطع کال` → قطع ویس‌کال
- `پخش` (ریپلای روی آهنگ) → پخش در کال
- `حذف سکوت` (ریپلای روی پیام کاربر) → برداشتن سکوت

## فایل‌ها

- `main.py` — فایل اصلی
- `voice_chat_player.py` — پخش موزیک در ویس‌کال
- `swear_words.py` — لیست فحش
- `config.py` — تنظیمات
- `Dockerfile` — برای Railway + ffmpeg
